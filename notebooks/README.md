# Notebooks Directory

Jupyter notebooks for exploration, prototyping, and analysis.

## Notebooks

### Exploration
- `01_data_exploration.ipynb` - Initial data analysis and visualization
- `02_network_analysis.ipynb` - Graph properties and statistics

### Algorithm Development
- `03_algorithm_prototyping.ipynb` - Testing TSP algorithms
- `04_algorithm_comparison.ipynb` - Benchmarking different approaches

### Visualization
- `05_visualization_experiments.ipynb` - Testing different viz libraries
- `06_map_styling.ipynb` - Metro map design iterations

## Usage

```bash
# Start Jupyter
jupyter notebook

# Or use Jupyter Lab
jupyter lab
```

## Best Practices

- Keep notebooks focused on single topics
- Export key functions to `src/` modules
- Document assumptions and findings
- Include markdown explanations
